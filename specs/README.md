## House style

- Canonical specs: `SPEC-NNN-{short-name}.md`
- Build/audit/fix prompts: `BUILD_SPEC_NNN_PROMPT.md`, `AUDIT_SPEC_NNN_PROMPT.md`, `FIX_SPEC_NNN_VX_Y_PROMPT.md`
- Audit outputs: `SPEC-NNN-audit.md`, `SPEC-NNN-vX-Y-audit.md`
- Severity rubric (CRITICAL / MAJOR / MINOR / QUESTION) applies across audits.
- Every normative requirement uses RFC-style MUST/SHOULD/MAY language.
- Every numeric threshold has a rationale paragraph; no magic numbers.
- Open questions (OQs) are explicit; never paper over uncertainty.

Pattern adapted from the macprovider-poc spec corpus (Augustas11/macprovider).
