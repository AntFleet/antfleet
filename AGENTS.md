# AGENTS.md

The AntFleet strategy substrate has been moved out of this public
repository. It is now operator-internal.

Public surfaces in this repo and at <https://www.antfleet.dev> may
reference section numbers (`§5`, `§7.1`, `§8`, `§15`, `§18.2`, etc.) —
those refer to the private strategy file. The conventions of those
citations are stable: when you see `§18.2` in a commit message or a
page comment, it points at the receipts-moat principle whether or not
this file is in front of you.

Operators with access to the strategy directory can read the cited
sections there. For everyone else: the code, the receipts on
<https://www.antfleet.dev/receipts>, the changelog, and the
architecture page together describe what AntFleet does. The strategy
doc describes why we do it that way and what comes next — distinct
material, deliberately kept off the public surface.

This file remains here as an anchor so the rename is discoverable.
